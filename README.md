A standalone GitHub-compatible git forge in TypeScript on Node 22: git smart-HTTP server (push/clone/fetch with pack negotiation and delta resolution), REST v3, GraphQL v4 and MCP endpoints, all served from one in-memory SHA-1 content-addressed object store. Conformance: 120/120 checks. Perf: 145 points (pack object cache, single-pass tag walk).

## Run it

```sh
node --experimental-strip-types main.ts
```
